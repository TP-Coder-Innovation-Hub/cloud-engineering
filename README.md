# Cloud Engineering

Architect, deploy, and operate cloud infrastructure. Assumes programming knowledge. Language-agnostic with YAML/pseudocode examples.

## Objectives

- Understand cloud fundamentals: providers, regions, responsibility models
- Use core services: compute, storage, databases, networking, IAM
- Master Infrastructure as Code with Terraform
- Apply modern practices: containers, serverless, monitoring, cost management
- Design for high availability, security, and well-architected workloads
